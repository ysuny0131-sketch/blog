# 블로그를 시작합니다

이곳은 별도의 데이터베이스 없이 운영하는 **정적 블로그**입니다.

글은 `content` 폴더에 Markdown 파일로 저장하고, `python3 build.py` 명령으로 HTML 페이지와 검색엔진용 파일을 함께 생성합니다.

## 앞으로 기록할 것

- 일하며 배운 것
- 미디어와 지역에 대한 생각
- 개인적인 관찰과 메모

검색엔진이 각 글을 직접 읽을 수 있도록 게시글마다 독립된 HTML 페이지가 생성됩니다.
